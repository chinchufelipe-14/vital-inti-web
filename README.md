# Vital-Inti Web

Primera versión del sitio oficial de Vital-Inti, marca mendocina de frutos secos y productos naturales.

## Estado actual

En desarrollo. Esta versión incluye:

- estructura principal de una página;
- navegación responsive;
- portada con identidad premium, natural y profesional;
- recorridos diferenciados para venta minorista y mayorista;
- espacios provisionales preparados para fotografías reales, logo, catálogo y datos definitivos;
- adaptación para computadora, tablet y celular.

## Contenido provisional

Todo texto o espacio marcado como **provisional** debe revisarse antes de publicar. No se incluyeron precios, mínimos de compra, teléfonos, horarios ni condiciones comerciales inventadas.

## Vista local

Abrir `index.html` en un navegador. No requiere instalación ni dependencias.

## Publicación

El sitio no está publicado ni desplegado. Cualquier publicación deberá hacerse únicamente después de la revisión y autorización de Vital-Inti.
